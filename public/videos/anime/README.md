Dépose ici la vidéo du personnage/moment d'anime : `clip.mp4`
(le chemin est défini dans `components/AnimeSection.tsx`, constante `ANIME_CLIP_SRC`).

La vidéo se lance automatiquement en boucle, muette (`autoplay`, `loop`, `muted`).
Tant que le fichier est absent, la section affiche un joli placeholder 🎬 au lieu de casser.
